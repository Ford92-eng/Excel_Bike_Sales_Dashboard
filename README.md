# Excel Bike Sales Dashboard
An interactive dashboard in Excel analysing bike purchasing behaviour using data cleaning, Pivot tables and charts

## Analysis
The dashboard analyses how income, age bracket, commute, education, marital status and location relate to bike purchasing behaviour.

## Skills Demonstrated
* Data cleaning
* IF formulas
* PivotTables
* Interactive slicers
* Data visualisation
